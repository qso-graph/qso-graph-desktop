# Getting Help

QSO Graph Desktop's current release is on the [Releases page](https://github.com/qso-graph/qso-graph-desktop/releases/latest).

| You want to… | Go to |
|---|---|
| Report a bug or ask for a feature | GitHub issues (use the issue forms) |
| Report a security problem | [SECURITY.md](SECURITY.md), privately, never in a public issue |
| Contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |

When reporting a problem, **Help → Save Diagnostics for Support…** (or **Export diagnostics** in
Settings' Troubleshooting panel) creates one archive with the application's logs and version
details, with credentials removed. Attach it if you're asked to;
it's sent only if you send it.

Please never post a password, API key or other credential in an issue.
