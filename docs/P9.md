# P9 acceptance registration: Stations

**Registered 2026-10-19**, before any of its code is written (`QGD-PRT-0003`). KI7MT added P9 the
same day: nothing an operator does is without a persona and a station. The exit gate is
`QGD-PRT-0109`: stations are made, edited and deleted, every field optional but the name and the grid, and each
one checked against ADIF's definitions, and every field of a TQSL station location held; each
persona's default station becomes active with it and the status bar names it; a station made from
a POTA park takes the park's grid, coordinates and state; Your station shows sunrise and sunset at
the active station; all of it survives a restart; screenshots approved by KI7MT in light and dark.
This document lists the tests that will show it. It is not a second copy of the requirements,
which stay in `QGD-SPEC-001` §3.3.

P9 depends on P6, for the personas a station is the default of, and on P5, for the ADIF
definitions and POTA's park list its values are checked against and filled from. Stations are the
core's (`QGD-PRT-0005`): they are kept by QG Storage and reached by the window through the core's
own contract, never through an extension.

## What P9 has to satisfy

`QGD-STN-0001`–`0009` and the station half of `QGD-HOM-0009`, with `QGD-SEC-0006` for every
station value that crosses a process boundary.

| Test | Required result |
|---|---|
| P9-record | A station is made, read back, edited and deleted through QG Storage, kept in `state.sqlite`, and is still there after a restart. Two personas share one station: it is stored once, and the callsign a log would carry (`STATION_CALLSIGN`) is the active persona's and changes with it, never stored on the station. Nothing of a station is written to the OS credential store or the credential core's files (`QGD-STN-0001`, `QGD-STN-0009`) |
| P9-adif | A fixture station holding a valid value in every field `QGD-STN-0002` lists, including boundary values (a 2- and an 8-character grid, zones 1 and 40 and 1 and 90, a 10-character locator through `MY_GRIDSQUARE_EXT`), round-trips unchanged through a restart. Every `MY_*` value is checked against the ADIF definitions in `reference.sqlite`: a grid of the wrong length or letters, a zone out of range, a state or county not in ADIF's subdivision list for the station's `MY_DXCC`, a malformed POTA, SOTA, WWFF or IOTA reference, are each refused with the field and the reason, and the value is not altered to fit. With ADIF's definitions not downloaded, the station can still be saved by name and the screen says its values could not be checked (`QGD-STN-0002`) |
| P9-optional | A station with no name, or a name of only spaces, is refused when made and when edited; so is one with no grid (`MY_GRIDSQUARE` or `MY_VUCC_GRIDS`). A station with a name and a grid saves, and every other field is optional: street, city and postal code save when given and are not required, and so do the operator's notes, over several lines. From the grid fills latitude and longitude with the grid's centre (`QGD-STN-0003`) |
| P9-kind | The kind is one of Home, Portable, Mobile or Remote, picked from a list; any other value is refused. Changing it changes no other field and no check: the same station saved under each of the four kinds is checked and stored identically but for the kind. No code path writes the kind into ADIF, shown by the static gate (`QGD-STN-0004`) |
| P9-active | A persona's default station becomes active when the persona does; the active station can be changed without changing the persona; the status bar names both; deleting the active station leaves none active and says so; all of it survives a restart. Changing the station drops what Home's cards showed, asks them again once when Home next shows, and discards a reply made for the previous station (`QGD-STN-0005`, `QGD-HOM-0005`) |
| P9-pota | From a POTA park reference, a new portable station takes the park's grid, coordinates and state from reference data and the reference into `MY_POTA_REF`, each value editable before saving. A park whose coordinates POTA publishes as unusable fills none from them and says so. With POTA's parks not downloaded, the screen says so instead of offering it (`QGD-STN-0006`) |
| P9-tqsl | For each field of a TQSL station location, the station holds the ADIF field TQSL checks it against: a fixture station for each entity TQSL has a page for (US, Canada, Russia, China, Australia, Japan, Finland) round-trips its state and county values through `MY_STATE` and `MY_CNTY`, a station on a grid line holds `MY_VUCC_GRIDS`, and the LoTW park field holds a park code. The list of TQSL fields is checked against TQSL's published `config.xml`, recorded with its version (`QGD-STN-0009`) |
| P9-grid-typed | The grid is entered by typing; the station holds no field ADIF does not define other than its name, kind, LoTW park and the operator's notes (KI7MT, 2026-10-22), shown by the contract's field list (`QGD-STN-0007`) |
| P9-not-tqsl | The static gate shows no code reads, writes or names TQSL's station data file (`QGD-STN-0008`) |
| P9-your-station | With a fixed clock and a station at a known grid active, Your station shows its name and grid, and sunrise and sunset there, matching a published reference for that place and date to the minute. It is started with the network unavailable and nothing cached, and draws the correct times while making no request. With no station active it says so and shows the clock alone; with a station active that has no grid and no coordinates, it names the station and says sunrise and sunset need its location. On the Air receives only the station's name, grid and coordinates through the extension API, never its street, city or postal code (`QGD-HOM-0009`, `QGD-STN-0003`, `QGD-APP-0002`) |
| P9-stays-local | Street, city, postal code and notes given to a fixture station appear in no outbound request the capture records, no application log line, and no support bundle; they leave only in an export the operator makes (`QGD-STN-0003`, `QGD-PSN-0011`) |
| P9-contract | A station command or reply off its shape (an unknown field, a wrong type, markup in a string, a value over its length) is refused at the boundary rather than coerced (`QGD-SEC-0006`) |
| P9-screens | Screenshot baselines of the Stations page with no stations, a list, the editor, and a station made from a park, and of Home with a station active, approved by KI7MT in light and dark; axe clean |

### Correction, 2026-10-22

P9-tqsl's check against TQSL's `config.xml`, and P9-grid-typed, P9-kind and P9-not-tqsl, had nothing
asserting them until these results were written; they were registered and not yet tested. They are
in `tests/station-gates.test.ts`, run by the `stations-storage` suite, and pass. Nothing they check
needed changing.
