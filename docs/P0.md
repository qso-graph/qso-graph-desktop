# P0 local preview acceptance registration

Registered before implementation on 2026-10-07 in qso-graph-devel #65.
Judge subsequently directed an unsigned local M3 build so the application can
be seen; signing does not block this preview. No release sign-off is implied.

- P0-local-build: pinned dependencies compile and the renderer is bundled.
- P0-local-policy: external URLs, unknown files and path traversal are refused.
- P0-local-smoke: one window launches and quits; expected text is visible.
- P0-local-hardening: sandbox and context isolation enabled, Node absent,
  network fetch refused and new windows denied.
- P0-local-package: an arm64 application bundle is produced with ASAR/fuses.
- P0-local-report: one verification command produces both reports, exits on
  failure and records pending acceptance evidence honestly.

**This document is a dated registration, not a gate list.** It records which
acceptance tests were registered before the local preview was implemented, and is
kept for that history.

What P0 requires is elsewhere, and is cited rather than restated here: the exit
gate is `QGD-PRT-0100`, the deferrals are `QGD-SCP-0003` (signing and
notarization) and `QGD-SCP-0004` (a second operating system, a CI matrix, a clean
VM of another OS), and sign-off is recorded in `data/part-signoff.json`.

The earlier closing line said full P0 acceptance retained three-OS, CI and
clean-VM gates. That contradicted `QGD-SCP-0004`, which defers all three until
Release 1, and it is corrected here rather than left to disagree with the
specification.
