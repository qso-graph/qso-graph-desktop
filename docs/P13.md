# P13 acceptance registration: Integrations

**Registered 2026-10-29**, before the Part is signed off (`QGD-PRT-0003`). The exit gate is
`QGD-PRT-0113`: with WSJT-X's messages replayed by `qso-graph-sim` from another machine, the
Monitor shows them; with the adapter off, no port is open; a sender not on the allow-list is
dropped unread. This document lists the tests that show it. It is not a second copy of the
requirements, which stay in `QGD-SPEC-001` §4.8, with `QGD-HOM-0015` to `QGD-HOM-0017` for the
three page abilities the Monitor needs.

P13 depends on P7, for the extension API its adapter and consumer are written against.
Integrations is core (`QGD-PRT-0005`): its listener is its own Rust utility process, and the
WSJT-X adapter and the Monitor are official extensions reaching it through the extension API.

## What P13 has to satisfy

`QGD-INT-0001`–`0011`, `QGD-INT-0020`–`0024`, `QGD-HOM-0015`–`0017`, with `QGD-INV-0005`
and `QGD-INV-0007` for everything that crosses a boundary.

|---|---|---|

| P13-only-listener | A static gate fails any TypeScript in the core or in what an extension ships that opens a socket, and any Rust outside `packages/integrations-core` that names a listening socket; each with a planted control (`QGD-INT-0002`, `QGD-INV-0005`) | `tests/network-static.test.mjs` |
