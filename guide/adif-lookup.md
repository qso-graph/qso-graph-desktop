# ADIF Lookup

Turn it on in **Settings → Extensions**, and download ADIF's definitions in **Settings → Reference
data**. ADIF is the format every logger uses to exchange QSOs.

Type anything: a field (`MY_GRIDSQUARE`), a band (`20m`), a mode (`FT8`), a DXCC entity, any ADIF
value. Exact names come first, then names that begin with what you typed, then entries that
contain it. Each match shows ADIF's own text, in ADIF's own columns, with nothing added. Type a
list's name (`Band`, `Mode`) to see the whole list, and narrow the matches to one list.

It works offline: everything is in the definitions you downloaded.
